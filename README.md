## 📌 Sobre o projeto

O **Links Senac RS** é um portal que centraliza os principais endereços e plataformas digitais relacionados ao Senac Rio Grande do Sul.

A proposta surgiu da necessidade de facilitar o acesso dos estudantes a diferentes serviços, evitando que precisem procurar individualmente cada plataforma ou guardar diversos endereços.

Com uma interface moderna, intuitiva e responsiva, o projeto organiza os links em categorias para proporcionar uma navegação simples e agradável.

## 🎯 Objetivos

- Centralizar os principais links do Senac RS.
- Facilitar o acesso dos alunos às plataformas educacionais.
- Organizar os serviços por categorias.
- Proporcionar uma experiência de navegação moderna e intuitiva.
- Garantir compatibilidade com computadores, tablets e smartphones.

## 🖥️ Funcionalidades

- **Navegação por categorias:** links organizados de acordo com suas finalidades.
- **Cards interativos:** cada plataforma possui seu próprio cartão de acesso.
- **Animações:** efeitos visuais de entrada, transições e interações.
- **Design responsivo:** adaptação para diferentes tamanhos de tela.
- **Interface moderna:** elementos visuais com cantos arredondados e sombras.
- **Acesso externo:** os links são abertos em novas abas.
- **Identidade visual:** utilização de uma paleta de cores personalizada.
